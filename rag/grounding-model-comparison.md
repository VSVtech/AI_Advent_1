# Локальная проверка RAG: Qwen 7B и 27B

Дата: 5 октября 2026. Устройство: Apple M4 Pro, 48 ГиБ unified memory. Ollama 0.34.4.

Выбран профиль **Qwen3.5 27B Q4_K_M, think=false** для финальной проверки утверждений и полноты. Проверка локальная. Генератор ответов чата не менялся. Отбор цитат по-прежнему использует Qwen2.5 7B; rewrite и эмбеддинги также не менялись.

## Основной прогон

| Метрика | Qwen2.5 7B | Qwen3.5 27B без thinking |
|---|---:|---:|
| Точный вердикт из трёх классов | 15/19 | 16/19 |
| Ложные подтверждения | 2 | 0 |
| Лишние отказы по исходной разметке | 0 | 2 |
| Ошибки выполнения / формата | 0 | 0 |
| Точная оценка полноты | 2/5 | 5/5 |
| Медиана проверки одного факта, с | 2.8 | 15.8 |
| p95 проверки одного факта, с | 8.8 | 21.4 |
| Память модели по Ollama, ГиБ | 5.2 | 16.6 |

27B устранила два ложных подтверждения: необоснованный вывод об удалении старых веток и перенос лимита MCP-вызовов на глубину ветвления. Все пять оценок полноты совпали с исходной разметкой: модель перестала повторно требовать уже указанное место хранения, метод dispose и другие имеющиеся сведения.

Цена — два дополнительных отказа: утверждение о долговременной памяти в конкретном режиме и поддерживаемые расширения, подтверждённые только объявлением IMAGE_EXTENSIONS. Эти примеры неоднозначны: 27B требует цитату с режимом и применением константы. Исходные эталоны после просмотра результатов не менялись; автоматическая метрика считает оба случая лишними отказами. Нужна независимая ручная разметка для окончательного вывода.

Обе модели отклонили внедрённую в цитату инструкцию, но выбрали contradicted вместо ожидаемого insufficient. Поэтому ошибка точного класса здесь не означает пропуск неподтверждённого факта.

## Thinking: пилот остановлен после таймаута

| Метрика на первом случае saved-test01-1 | 7B | 27B без thinking | 27B с thinking |
|---|---:|---:|---:|
| Результат | supported | insufficient | error |
| Время, с | 8.8 | 20.3 | 240.0 |

Планировались три заранее выбранных сложных утверждения и один вопрос полноты. Первая проверка не завершилась за 240 секунд; пилот остановлен, отчёт явно помечен complete=false. Остальные случаи не оценены. Таймаут — ошибка выполнения, а не смысловой вердикт. Делать вывод о качестве reasoning по этому прогону нельзя; выбран обычный профиль, завершивший весь набор без ошибок.

## Условия и ограничения

- Набор зафиксирован до сравнения: 7 сохранённых и 12 синтетических утверждений, 5 случаев полноты. Ожидания заданы Codex, не независимым человеком. Эталоны моделям не передавались.
- Проверены именно модели проверки, на одинаковых утверждениях и буквальных цитатах. Поиск и генерация ответов повторно не запускались. Это не доказательство улучшения всего RAG на новых вопросах.
- Числовые guardrails одинаково отключены в этом модельном сравнении; в рабочем RAG они включены. В частности, ошибку с числовым лимитом рабочая версия может отсечь и без 27B.
- Промпты общие и неизменные. Sampling и лимиты контекста соответствуют профилям: 7B temperature=0, verify context=16384; 27B context=8192 и рекомендованные для неё параметры. Сравниваются рабочие профили, а не только размер модели при тождественных параметрах.
- Один прогон, seed=42; начальная загрузка включена во время. Медиана относится к одному факту, не к полному ответу. Шесть последовательных проверок и исправление могут занимать минуты.
- Ollama сообщила полное размещение 27B на GPU: 17 837 955 480 байт (16,6 ГиБ). Это память модели, не всех процессов RAG. После загрузки на диске оставалось около 289 ГиБ. Наличие swap само по себе не измеряет текущую нехватку памяти.
- Проверка совместной загрузки показала, что при загрузке 7B текущая Ollama выгружает 27B. Их одновременное удержание не подтверждено: в рабочей цепочке будут переключения моделей и дополнительное время загрузки. Настройки распределения памяти Ollama не изменялись.
- Неполный или некорректный JSON, таймаут и обрезанный вывод не считаются подтверждением. Текст внутреннего рассуждения не публикуется и в отчётах не сохраняется.

## Воспроизводимость

Работающий сервис перезапущен с 27B и `think=false`. Через HTTP `/rag` проверены:
отказ `insufficient` для saved-test01-1, подтверждение `supported` для saved-test05-1,
отсутствие пропусков в coverage-test05. Все три запроса завершились HTTP 200;
identity подтверждает 27B и включённые числовые guardrails. Этот smoke-тест
не вызывает облачный генератор чата. Также прошли 525 автоматических тестов,
lint и production build.

Исходные данные: [фиксированный набор](grounding-judge-cases.json). Полные результаты: [7B](grounding-model-7b.json), [27B](grounding-model-27b.json), [thinking-пилот](grounding-model-27b-thinking.json). В JSON есть входы, вердикты, обоснования, параметры, тайминги и хеши.

Хеш набора: `6133a8fd8ea898a954bf91ad338fc3bb0c3c3012d08937fe9581303313666c36`.
Модель `qwen2.5:7b`: `845dbda0ea48ed749caafd9e6037047aa19acfcfd82e704d7ca97d631a0b697e`.
Модель `qwen3.5:27b-q4_K_M`: `64ae5b1d651fb2709d5928ccb8dcfb4bb2cc9c2c8001ac34497e36a6cf905b59`.

```bash
pnpm rag:judge:compare --profile=7b
pnpm rag:judge:compare --profile=27b
pnpm rag:judge:compare --profile=27b-thinking
```

Настройка профиля: `pnpm rag:judge:configure --model=qwen3.5:27b-q4_K_M --think=false`, затем перезапуск `pnpm rag:server`. Возврат: `pnpm rag:judge:configure --model=qwen2.5:7b --think=false` и перезапуск. Профиль хранится локально и не коммитится.
