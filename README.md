# DeepSeek Chat

Локальный одностраничный чат с DeepSeek V4 Flash через Responses API. API-токен
используется только серверным маршрутом и не передаётся в браузер. История
хранится в памяти вкладки и сбрасывается при обновлении страницы. Для каждого
ответа можно выбрать формат Text, JSON, XML или YAML. Структурированные ответы
проверяются на сервере и выводятся с подсветкой синтаксиса; при ошибке
выполняется не более трёх повторных запросов к модели.
Целевая длина передаётся модели как диапазон 87,5–112,5% от указанного значения,
но его верхняя граница не может превышать технический максимум. Технический
`max_output_tokens` рассчитывается сервером как цель плюс 20%, но запас не может
быть меньше 500 или больше 2000 токенов. Это оставляет место для завершения и
закрытия структурированных форматов. После ответа рядом отображается фактическое
число выходных токенов из статистики DeepSeek.

Рядом с форматом ответа в «Чате» задаётся температура от 0 до 2 (шаг поля 0,1,
по умолчанию 1). Она передаётся отдельным параметром `temperature` во все
запросы чата, включая повторные проверки формата, и работает с обоими режимами
системного промпта. Пустое или недопустимое значение не позволяет отправить
запрос; сервер также проверяет диапазон. Настройка не влияет на «Сравнение».

Бейджик с именем модели в шапке «Чата» — это выбор модели, а не просто
подпись. Список моделей запрашивается с сервера (`GET /api/models`, который
вызывает `GET https://api.deepseek.com/models` тем же API-токеном) при
загрузке страницы — показываются только модели, реально доступные по текущему
токену, а не жёстко зашитый список. Если запрос списка не удался или токен не
настроен, доступной остаётся только модель по умолчанию (`deepseek-v4-flash`),
и чат продолжает работать со статичным бейджиком. Выбранная модель передаётся
параметром `model` во все запросы чата, включая повторные проверки формата;
сервер проверяет, что это непустая строка в разумных пределах, а неизвестный
идентификатор модели отклонит сам DeepSeek. Настройка не влияет на
«Сравнение» и «Бенчмарк» — «Сравнение» всегда использует модель по умолчанию,
чтобы сравнение системных промптов не смешивалось со сравнением моделей, а
«Бенчмарк» сам запускает запрос сразу на всех доступных моделях (см. ниже).

## Разделы

В меню слева доступны «Чат», «Сравнение» и «Бенчмарк». На узких экранах меню
располагается сверху. «Чат» открыт по умолчанию и содержит существующий
диалог со всеми настройками. Переключение разделов не сбрасывает историю,
черновик сообщения или системный промпт и не прерывает текущую генерацию.

### Сравнение системных промптов

Вверху раздела находится общая задача, ниже — пять чатов в один ряд. На узких
экранах доступна горизонтальная прокрутка колонок. Системный промпт каждого
варианта показан над его историей:

1. Пустой системный промпт, исходный пользовательский запрос.
2. Системный промпт `решай пошагово`, исходный запрос.
3. Пустой системный промпт, к запросу добавляется ` Решай пошагово.`.
4. Отдельный запрос `Составь промпт для решения задачи: ` + задача. Полученный
   промпт становится пользовательским сообщением второго запроса. Оба запроса
   без системного промпта; история создания промпта не передаётся в чат решения.
   Сам сгенерированный промпт можно раскрыть над ответом.
5. Системный промпт `Создай группу экспертов: аналитик, инженер, критик. Получи
решение от каждого и одно общее`. Это один ответ модели, не отдельные агенты.

Кнопка «Сравнить» запускает варианты параллельно. Один раунд — до шести
запросов к DeepSeek (два в варианте 4); автоматических перезапросов нет.
Везде используется V4 Flash с отключённым reasoning, текстовым ответом и
техническим лимитом 8000 токенов на запрос. Инструкции целевой длины и формата
из вкладки «Чат» не добавляются; пустой system означает отсутствие `instructions`.
Количество токенов ответа и создания промпта отображается отдельно.

Каждая колонка хранит собственную историю завершённых решений. На следующий
раунд передаются только фактические запросы модели и её завершённые ответы;
прерванные и ошибочные ответы в контекст не попадают. Ошибка одного варианта
не останавливает остальные. «Остановить» отменяет текущие запросы, а очистка
сравнения сбрасывает только его истории и не затрагивает обычный чат.

### Бенчмарк моделей

Один и тот же промпт без системного промпта и без истории отправляется по
одному разу на каждую модель, реально доступную по текущему токену (тот же
список, что и в шапке «Чата»). Для каждой модели показываются: время ответа
(измеряется на сервере — от начала запроса к DeepSeek до получения полного
ответа; каждый запрос нестримовый, чтобы время было сопоставимо между
моделями), входные и выходные токены из статистики DeepSeek и оценка
стоимости в долларах. Самая быстрая завершившаяся модель подсвечивается в
таблице. Полный текст ответа каждой модели можно раскрыть под строкой.

Лимит ответа на модель — 2000 токенов (`BENCHMARK_MAX_OUTPUT_TOKENS` в
`lib/benchmark.ts`), без ограничения на целевую длину. Запросы выполняются
параллельно; «Остановить» отменяет ещё не завершившиеся запросы, ошибка одной
модели не останавливает остальные. Очистка сбрасывает только результаты
бенчмарка.

Оценка стоимости считается по таблице цен в `lib/model-pricing.ts` (за 1 млн
токенов: обычный вход / вход из кэша / выход), которая учитывает раздельные
цены на кэшированные и некэшированные входные токены DeepSeek. Таблица
заполнена только для известных моделей (`deepseek-v4-flash`,
`deepseek-v4-pro`) по опубликованным на начало сентября 2026 ценам DeepSeek —
для остальных моделей и при изменении цен показывается «—» вместо стоимости.
Это оценка, а не биллинг DeepSeek: при появлении новых моделей или изменении
цен обновите таблицу вручную.

## Системный промпт

Между настройками ответа и вводом сообщения показан системный промпт.
По умолчанию включены «Использовать системный промпт» и «Использовать промпт
из селекторов»: поле доступно только для чтения и обновляется при изменении
формата или целевой длины.
Сервер формирует тот же текст самостоятельно.

Снимите «Использовать системный промпт», чтобы полностью отключить его:
поле и выбор источника скрываются, а `instructions` не передаётся в DeepSeek.
Текст и выбранный источник сохраняются при обратном включении. Даже пустой
кастомный промпт не мешает отправке в выключенном режиме. Температура, лимит
токенов и проверка формата продолжают работать, но требований к целевой длине
и формату в системном промпте больше нет — укажите их в пользовательском
сообщении. При ошибке формата уточнение для повторной попытки отправляется
как временное сообщение `user`, без включения системного промпта и без
накопления этих уточнений в истории.

Снимите «Использовать промпт из селекторов», чтобы редактировать промпт.
При первом переключении в поле
копируется текущий автоматический промпт; дальнейшие переключения сохраняют
кастомный текст в памяти вкладки. Можно ввести от 1 до 20 000 символов.
Кастомный промпт **заменяет**, а не дополняет инструкции формата и целевой длины.
При этом технический лимит токенов и серверная проверка выбранного формата
сохраняются: нужные требования к формату и длине следует описать в своём тексте.
При ошибке формата к выбранному промпту добавляется краткое уточнение для
повторной попытки (не более трёх), без добавления невалидных ответов в историю.

Выбранный промпт отправляется в `instructions` каждого нового запроса и не
накапливается в истории сообщений. Изменение промпта влияет только на следующие
запросы.

## Требования

- Node.js 22.13 или новее
- pnpm
- API-токен DeepSeek с положительным балансом

## Запуск

1. Установите зависимости:

   ```bash
   pnpm install
   ```

2. Создайте `.env.local` на основе `.env.example`:

   ```dotenv
   DEEPSEEK_API_KEY=ваш_токен
   ```

3. Запустите приложение:

   ```bash
   ./start.sh
   ```

   Скрипт можно запускать из любой директории. Альтернативный способ —
   `pnpm dev` из корня проекта.

4. Откройте [http://localhost:3000](http://localhost:3000).

### Запуск двойным кликом на macOS

Откройте в Finder файл `launch.command`. Он сам откроет Terminal и запустит
сервер — вводить команды не требуется.

## Команды

- `pnpm dev` — локальная разработка
- `pnpm build` — production-сборка
- `pnpm lint` — статическая проверка
- `pnpm test` — автоматические тесты API и потокового парсера

DeepSeek тарифицирует API-запросы отдельно. Токен не следует добавлять в Git или
в переменные с префиксом `NEXT_PUBLIC_`.
