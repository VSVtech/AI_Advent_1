# DeepSeek Chat

Локальный одностраничный чат с DeepSeek V4 Flash через Responses API. API-токен
используется только серверным маршрутом и не передаётся в браузер. История
хранится в памяти вкладки и сбрасывается при обновлении страницы. Для каждого
ответа можно выбрать формат Text, JSON, XML или YAML. Структурированные ответы
проверяются на сервере и выводятся с подсветкой синтаксиса; при ошибке
выполняется не более трёх повторных запросов к модели.
Целевая длина передаётся модели как диапазон 87,5–112,5% от указанного значения,
но его верхняя граница не может превышать технический максимум. Технический
`max_output_tokens` рассчитывается сервером как цель плюс 20%, но запас не может
быть меньше 500 или больше 2000 токенов. Это оставляет место для завершения и
закрытия структурированных форматов. После ответа рядом отображается фактическое
число выходных токенов из статистики DeepSeek.

## Требования

- Node.js 22.13 или новее
- pnpm
- API-токен DeepSeek с положительным балансом

## Запуск

1. Установите зависимости:

   ```bash
   pnpm install
   ```

2. Создайте `.env.local` на основе `.env.example`:

   ```dotenv
   DEEPSEEK_API_KEY=ваш_токен
   ```

3. Запустите приложение:

   ```bash
   ./start.sh
   ```

   Скрипт можно запускать из любой директории. Альтернативный способ —
   `pnpm dev` из корня проекта.

4. Откройте [http://localhost:3000](http://localhost:3000).

### Запуск двойным кликом на macOS

Откройте в Finder файл `launch.command`. Он сам откроет Terminal и запустит
сервер — вводить команды не требуется.

## Команды

- `pnpm dev` — локальная разработка
- `pnpm build` — production-сборка
- `pnpm lint` — статическая проверка
- `pnpm test` — автоматические тесты API и потокового парсера

DeepSeek тарифицирует API-запросы отдельно. Токен не следует добавлять в Git или
в переменные с префиксом `NEXT_PUBLIC_`.
